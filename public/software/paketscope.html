01 / PENGELOLAAN APLIKASI · V3

Inventaris Linux yang lebih jelas.

PaketScope 3 dikembangkan sebagai pengelola aplikasi desktop native berbasis Qt. Selain inventaris dan operasi APT terkonfirmasi, System & Code Lab menyediakan snapshot sistem read-only serta viewer dan analisis statis untuk source code yang dipilih pengguna. Mode Administrator bersifat opt-in, meminta persetujuan Polkit untuk setiap aksi, dan tidak menjalankan seluruh aplikasi sebagai root. Biner hanya diperiksa metadatanya; fitur ini bukan decompiler. Inventaris Flatpak dapat dilihat, tetapi perubahan paket Flatpak belum tersedia.

01 / FONDASI V3

Berguna sejak dirancang.

Fondasi v3 mengutamakan inventaris yang dapat dijelaskan, alur kerja sederhana, layanan aplikasi yang terpisah dari antarmuka, dan perilaku sistem yang mudah diperiksa.

01

Inventaris lokal

Membaca metadata paket yang terpasang melalui dpkg-query dan Flatpak. Hasil diurutkan secara konsisten dan sumber yang tidak tersedia ditampilkan sebagai diagnostik.

02

Pencarian dan filter

Temukan aplikasi berdasarkan nama, versi, sumber, ID, asal Flatpak, atau cabang. Tabel dapat diurutkan tanpa memuat ulang data sumber.

03

Pemeriksaan pembaruan

Dijalankan hanya saat diminta pengguna. APT menggunakan metadata lokal; pengecekan Flatpak dapat menghubungi remote yang dikonfigurasi. Tidak ada paket yang otomatis dipasang.

04

Ekspor yang jelas

Ekspor CSV memuat baris yang terlihat. Cadangan lengkap dapat dienkripsi dengan AES-256-GCM; pembukaan cadangan ke JSON biasa memerlukan persetujuan eksplisit.

05

Prinsip keamanan

Perubahan paket APT dimulai dari simulasi dan daftar perubahan yang ditinjau pengguna, dilanjutkan konfirmasi aplikasi serta autentikasi sistem melalui polkit. Aplikasi tidak dijalankan sebagai root, tidak memanggil shell, tidak menjalankan autoremove, dan tidak melakukan upgrade massal otomatis. Flatpak masih read-only.

06

Local-first

Tidak ada akun, backend jarak jauh, analytics, atau telemetry. Daftar aplikasi tetap di perangkat; koneksi remote hanya mungkin pada pemeriksaan pembaruan Flatpak yang dimulai pengguna.

02 / PRIVASI & KEAMANAN

Data lokal. Tindakan eksplisit.

PaketScope berjalan sebagai pengguna biasa untuk inventaris, pencarian, ekspor, dan System & Code Lab. Code Inspector membaca source lokal sebagai teks/AST dan tidak menjalankan proyek yang dianalisis. Petunjuk tinjauan statis hanya heuristik: temuan tidak otomatis membuktikan kerentanan, dan hasil kosong tidak membuktikan kode aman.

Mode Administrator dibatasi ke metadata sistem atau pembacaan satu file teks yang diizinkan, dengan konfirmasi aplikasi dan autentikasi Polkit per aksi. Helper tidak menerima shell atau perintah bebas dan tidak mengubah file. Tidak ada tugas jaringan latar belakang atau pengiriman daftar aplikasi/hasil inspeksi ke layanan pihak ketiga.

Cadangan terenkripsi menggunakan AES-256-GCM dengan salt dan nonce acak untuk setiap berkas, serta kunci turunan scrypt. Kata sandi tidak disimpan oleh aplikasi. Jika kata sandi hilang, cadangan tidak dapat dipulihkan.

Ekspor CSV dan JSON hasil dekripsi merupakan berkas teks biasa yang dapat mengungkap perangkat lunak yang digunakan. Simpan hanya di lokasi tepercaya dan hapus salinan sesuai kebutuhan. Pada sistem POSIX, berkas ekspor dibuat dengan izin pemilik saja (0600), dan nilai CSV yang menyerupai formula spreadsheet dinetralkan.

Enkripsi dalam kode sumber bukan pengganti audit independen. Sebelum rilis publik, proyek masih memerlukan pengujian pada instalasi Debian yang bersih, peninjauan dependensi, pengemasan bertanda tangan, dan tinjauan keamanan.
